# 12. Upgrade definitions and shop

**Goal:** Let players improve clipping, quality, and publishing.

**Scope:** Add a small set of upgrades with costs, effects, and purchase rules; display each effect in plain language.

**Depends on:** 02, 04, 11.

**Acceptance checks:** Affordable upgrades can be purchased; unaffordable upgrades cannot; purchases deduct views and change the relevant loop behavior; costs/effects are data-driven.
