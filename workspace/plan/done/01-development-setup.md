# 01. Development setup

**Goal:** Make the empty project reliably runnable and buildable.

**Scope:** Confirm Node/npm requirements, install the declared Phaser/TypeScript/Vite dependencies, and resolve any configuration issues in the scaffold.

**Depends on:** None.

**Acceptance checks:** `npm install`, `npm run dev`, and `npm run build` work; the dev page loads without console errors; setup instructions match the repository.
