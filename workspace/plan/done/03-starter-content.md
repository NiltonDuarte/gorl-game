# 03. Starter content data

**Goal:** Provide a small data-driven set of streams and moments for the first playable loop.

**Scope:** Add a few channels with distinct pace/audience profiles and ordinary plus notable moments. Clearly mark any invented names or jokes as placeholders pending canon approval.

**Depends on:** 02.

**Acceptance checks:** Content can be selected by ID without scene-specific data; categories are descriptive tags rather than canon claims; each moment has enough information to support rarity, setup/payoff, and audience fit.
