# 07. Moment selection and snipping

**Goal:** Make manual clipping the first meaningful player action.

**Scope:** Select a timeline moment, adjust simple start/end trims, derive trim quality, and create a draft clip.

**Depends on:** 02, 04, 06.

**Acceptance checks:** Only a selected moment can be snipped; trim choices visibly affect quality; player receives clear feedback when a draft is created.
