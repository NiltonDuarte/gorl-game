# 20. MVP pacing review

**Goal:** Tune the first session to deliver a manual win, then a useful automation unlock.

**Scope:** Play through the full loop and adjust moment cadence, view rates, upgrade prices, helper unlock, and milestone timing.

**Depends on:** 08, 10, 12, 13, 14, 17.

**Acceptance checks:** A new player can understand clipping without outside instructions; choice visibly affects results; first upgrade matters; offline return is useful; next objective is clear after the first win.

**Implemented:** Kept the starter stream's first moment delay at 3 seconds, set moment cadence to 13–23 seconds, and retained the 100-view first upgrade, 240-view helper, and 3-fan stream milestone. A browser smoke check confirmed the manual clip flow and first purchase objective are visible; tune further using playtest feedback.
