# 17. Return recap

**Goal:** Explain progress earned while away and point to the next action.

**Scope:** Summarize views earned, notable clip performance, and any newly available opportunities after offline simulation.

**Depends on:** 14, 16.

**Acceptance checks:** Recap appears only when there is meaningful offline progress; values match the state change; player can dismiss it and continue.

**Implemented:** Meaningful returns produce a dismissible overlay with earned views, helper drafts, stream unlocks, and the top clips by newly earned views. Recap data was checked against simulated state changes; UI copy and layout are included in the successful build.
